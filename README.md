# 🛒 Walmart Sales Analysis | Python, SQL & Tableau

## 📌 Project Overview

This project focuses on analyzing Walmart's weekly sales data to identify sales trends, compare store performance, and explore the relationship between weekly sales and factors such as holidays, temperature, CPI, and unemployment.

The project combines **Python for data cleaning and exploratory data analysis (EDA), SQL for data querying, and Tableau for Business Intelligence (BI) dashboards** to transform raw sales data into meaningful business insights.

## 🎯 Project Objectives

* Analyze weekly sales trends across different stores.
* Identify top-performing stores based on weekly sales.
* Examine sales patterns during holiday and non-holiday weeks.
* Explore the relationship between sales and external factors.
* Calculate key sales performance metrics.
* Develop interactive Tableau dashboards for data visualization.
* Generate insights to support data-driven business decisions.

## 📂 Dataset Information

The dataset contains **6,435 records** of Walmart store-level weekly sales data.

### Key Columns

| Column       | Description                                        |
| ------------ | -------------------------------------------------- |
| Store_Number | Unique identifier for each store                   |
| Date         | Date associated with weekly sales                  |
| Weekly_Sales | Total sales recorded for the store during the week |
| Holiday_Flag | Indicates whether the week includes a holiday      |
| Temperature  | Temperature recorded for the corresponding period  |
| CPI          | Consumer Price Index                               |
| Unemployment | Unemployment rate                                  |

## 🔄 Project Workflow

### 1. Data Cleaning & Preparation — Python

* Loaded the dataset using Pandas.
* Checked the dataset structure, data types, and missing values.
* Converted the date column into an appropriate date format.
* Cleaned and prepared sales values for analysis.
* Performed exploratory data analysis to understand the dataset.

### 2. SQL Analysis

Used SQL queries to explore business questions, including:

* What are the total and average weekly sales?
* Which stores generate the highest weekly sales?
* Which dates have the highest sales?
* How do sales differ between holiday and non-holiday weeks?
* What is the contribution of individual stores to overall sales?
* How do sales vary over time?

### 3. Business Intelligence — Tableau

Created visualizations to explore:

* Overall sales performance.
* Store-wise sales comparisons.
* Weekly sales trends.
* Holiday sales patterns.
* Sales distribution across stores.

## 📊 Key Performance Indicators (KPIs)

The analysis focuses on the following metrics:

* **Total Weekly Sales:** Aggregate sales across the dataset.
* **Average Weekly Sales:** Average sales value per record.
* **Total Stores:** Number of distinct stores represented in the dataset.
* **Highest Weekly Sales:** Maximum weekly sales value.
* **Store Sales Contribution:** Percentage contribution of each store to overall sales.

## 💡 Business Questions

This project explores important retail business questions:

1. Which stores have the highest average weekly sales?

3. Do holiday weeks show different sales patterns?
